# Fonts

Harmonix uses **Aeonik** (CoType Foundry), 14 weights. Aeonik is a commercial font: the licence does
not allow redistribution, so the `.otf` files are **not** in this repo.

Get `Aeonik-*.otf` from the Harmonix team (or your own licence) and drop them in this folder.
`colors_and_type.css`, `brand.json` and the Remotion project all load them from here.
